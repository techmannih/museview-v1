# Routing and reproducibility

V1.1 is independently placed on a 50 × 35 mm outline following the supplied visual brief. The source circuit, local bypasses, FPC fanout, copper planes and RF exclusion remain explicit in `index.circuit.tsx`. All assembly is on top. Signal routing uses the two outer copper layers; L2 is GND and L3 is VDD_IO.

The remaining copper is generated by `scripts/route-grid.py` on a 0.05 mm grid from tscircuit's exported geometry. USB data contacts escape under the receptacle; active ESP32 signal pads escape toward the free area under the module. Local ground and I/O supply spurs terminate directly on their planes. The router checks expanded pad, fixed-track, via, hole, RF and board-edge obstacles, then joins each remaining net. It does not use another board's copper or the earlier larger MuseView layout.

`routing/input.simple-route.json` is the exact native routing input. `routing/geometry.json` contains the source/port/placement records needed by this board-specific generator, including the explicit USB ESD bypass and 39 fixed vias. These are regeneration inputs, not manufacturing files. Python 3.11+ and the pinned NumPy package in `routing/requirements.txt` are needed only to regenerate routing. Bun builds replay the checked copper without Python.

```sh
python3 -m venv .venv
.venv/bin/pip install -r routing/requirements.txt
PYTHON=.venv/bin/python bun run regenerate:routing
bun run verify
```

The generator refuses to replace `pcb-routes.json` if any connection fails. `scripts/board-router.ts` then replays that copper only when the geometry/net fingerprint matches the current tscircuit input. Native DRC, exact endpoint checks and the separate Gerber short analysis still run. GitHub CI regenerates the copper, checks that the saved file matches, and runs the full verification suite.

When changing electrical or physical geometry, capture fresh native input with `tsci build --autorouter-dump-srj all --autorouter-debug` after temporarily removing `algorithmFn: boardRouter`. Refresh the geometry records from that same source revision, update the board-specific escape positions if required, regenerate the routes and restore the replay router. Never copy a fingerprint onto stale routes. Schematic-only label edits do not change the fingerprint.

After verification, update and compare the 2D and 3D snapshots and run `bun run export:release`. All exported drills are through plated L1–L4 or nonplated. There are no blind/buried drills. The bottom stencil is intentionally empty; bottom copper is routing, with no fitted components. Recheck JLC rotations, stackup and physical USB/camera operation before production.

The snapshot tool's optional selector route-cache writer may warn that a via selector is ambiguous. That secondary cache is not used; the explicit geometry-guarded route file supplies the copper.
